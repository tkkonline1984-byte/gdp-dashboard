TKK ONLINE Product Intake & Conversion Hub v2.1.0 UPDATE
========================================================

เริ่มใช้งานบน Windows
1. แตก ZIP ทั้งหมด
2. ตั้งค่า .streamlit\secrets.toml ตาม USER_GUIDE_TH.md
3. ดับเบิลคลิก install.bat ครั้งแรก
4. เปิดระบบด้วย run.bat

เมนูหลัก
- ส่งรูปสินค้า + รหัส 13 หลัก + ตำแหน่งบนแผนที่ร้าน
- รายการ แผนที่ปัจจุบัน และประวัติการย้ายสำหรับผู้ดูแล
- PDF to JPG
- PDF to Excel
- JPG to Excel
- Excel to PDF

สำคัญ
- Repository เก็บข้อมูลต้องเป็น Private
- ห้ามใส่ Token จริงใน GitHub หรือส่ง Token ทางแชต
- คู่มือฉบับเต็มอยู่ที่ USER_GUIDE_TH.md
- โปรแกรมใส่กรอบรูปเดิมเปิดด้วย run_batch_frame.bat
