TKK ONLINE - Auto Background Remove + Frame
============================================

โปรเจกต์ Windows พร้อมใช้งาน
- ลบพื้นหลังรูปสินค้าอัตโนมัติ
- ลดขอบขาว/เทารอบสินค้า
- ขยายสินค้าให้ใหญ่และอยู่กลางกรอบ
- 1 รูปสินค้า = 1 ไฟล์ PNG
- รักษาชื่อไฟล์เดิม และลบ (1) ท้ายชื่อ
- รวมผลลัพธ์เป็น outputs.zip
- ดับเบิลคลิก run.bat เพื่อใช้งาน
- run.bat จะติดตั้งไลบรารี Python ให้อัตโนมัติ
- ถ้าไม่มี Python จะลองติดตั้งผ่าน Windows Package Manager (winget)

ไฟล์สำคัญ
------------
run.bat
    ไฟล์สำหรับดับเบิลคลิกใช้งาน

batch_tkk_frame.py
    โปรแกรมหลัก

requirements.txt
    รายการไลบรารี Python

frame.png
    กรอบตัวอย่าง 1254x1254
    สามารถแทนที่ด้วยกรอบ TKK ONLINE ของจริงได้
    แนะนำให้ใช้ชื่อ frame.png

products/
    นำรูปสินค้าต้นฉบับมาใส่ในนี้

outputs/
    โปรแกรมจะล้างและสร้างผลลัพธ์ใหม่ทุกครั้ง

outputs.zip
    โปรแกรมจะสร้างอัตโนมัติหลังประมวลผล

วิธีใช้
-------
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ TKK_Auto_Frame_Windows
3. ถ้ามีกรอบ TKK ONLINE ของจริง ให้แทนที่ frame.png
4. นำรูปสินค้าใส่ในโฟลเดอร์ products
5. ดับเบิลคลิก run.bat
6. รอจนขึ้นคำว่า "เสร็จแล้ว"
7. โปรแกรมจะเปิดโฟลเดอร์ outputs ให้อัตโนมัติ
8. ไฟล์ outputs.zip จะอยู่ข้าง run.bat

การตั้งค่าขนาดสินค้า
---------------------
เปิด batch_tkk_frame.py แล้วหา:

ZONE_FILL_X = 0.985
ZONE_FILL_Y = 0.985

ค่าใกล้ 1.00 = สินค้าใหญ่ขึ้น

พื้นที่วางสินค้า
----------------
โปรแกรมอ้างอิงกรอบ 1254x1254:

REF_ZONE_X0, REF_ZONE_X1 = 20, 1230
REF_ZONE_Y0, REF_ZONE_Y1 = 255, 915

ถ้าใช้ frame.png ขนาดอื่น โปรแกรมจะปรับพิกัดตามสัดส่วนให้อัตโนมัติ

หมายเหตุ
--------
- โปรแกรมจะล้างโฟลเดอร์ outputs ทุกครั้งก่อนประมวลผลใหม่
- หากชื่อไฟล์ซ้ำหลังลบ (1) โปรแกรมจะเติม _2, _3 เพื่อไม่ให้ไฟล์ทับกัน
- ภาพที่มี Alpha โปร่งใสอยู่แล้วจะใช้ Alpha เดิมโดยไม่ GrabCut ซ้ำ
- การลบพื้นหลังอัตโนมัติอาจต้องปรับค่าในกรณีที่สินค้าและพื้นหลังมีสีใกล้กันมาก
